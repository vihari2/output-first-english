# Study Guides

This folder contains supporting materials to help you organize your independent English studies. Each file covers a different area:

| File | Contents |
| :--- | :--- |
| [coursebooks.md](coursebooks.md) | Recommended coursebook series by CEFR level (A1–C2), self-study guidance, and digital sources for legally finding materials and audio. |
| [other-resources.md](other-resources.md) | Online tools, useful websites, book recommendations by level, and supplementary grammar and study materials. |
| [speaking.md](speaking.md) | Instructions and suggestions for practicing conversation using Google Meet and Shadowing. |
| [writing-guide.md](writing-guide.md) | A guide to improving your English writing, with practice ideas and journal prompts. |

Use the guides according to your current goals and combine them with a regular routine of reading, writing, listening, and speaking.
